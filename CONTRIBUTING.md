## Contributing

Thank you for considering contributing to Leaflet-Geoman.

Follow these steps to get up and running:

1.  clone the repository
2.  Make sure you run the node version specified in package.json under "engines" or run `nvm use`
3.  run `pnpm install`
4.  run `pnpm start` to compile dev version and use watch mode
5.  run `pnpm run cypress` to launch the test suite (also nice for TDD)
6.  run `pnpm run test` to run cypress tests
7.  run `pnpm run lint` to check the code with eslint
8.  run `pnpm run prepare` to compile the build version
